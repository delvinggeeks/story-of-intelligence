# ADR-0001: Retain Educational Domain Model for v1.0

- **Status:** Accepted (recorded from source)
- **Date:** Architecture phase source record, 2026-08-01
- **Decision:** Retain the name **Educational Domain Model (EDM)** for v1.0.

## Context

The source considered renaming EDM to Learning Intelligence Model (LIM) to reflect possible future application beyond education.

## Decision and rationale

Keep EDM because the current evidence supports AI and mathematics education. Broader application to other domains remains a hypothesis; names must follow validated scope rather than anticipated ambition.

## Review trigger

After successful application of the same model to at least one substantially different domain, evaluate a rename to LIM as part of EDM v2.0.
